Auto Clicker is a small, portable auto clicker for Windows.

It is written in pure C99 against the Win32 API, with no frameworks and no runtime dependencies beyond what ships with Windows. The interface is drawn entirely by hand, which makes a consistent dark theme possible, and full per-monitor DPI awareness keeps it crisp on scaled and multi-monitor setups.

Clicks are scheduled against a high-resolution clock instead of a simple sleep loop, so the interval never drifts. Very long intervals still react to Stop immediately, and all coordinates are handled in physical pixels, the part most similar tools get wrong on scaled displays.

— Polina “Aura” N. & Julia Nechaevskaya

Usage

  • Set the interval in hours, minutes, seconds and milliseconds, all four fields are editable, and the mouse wheel adjusts any of them.
  • Choose the mouse button (left, right, middle) and click type (single or double).
  • Repeat a fixed number of times, or continue until stopped.
  • Click at the current cursor position, or pick a fixed location with a three-second countdown.
  • Press F6 anywhere to start and stop. The hotkey can be reassigned in the window.
  • Settings are saved in autoclicker.ini next to the executable, so the whole folder can be moved anywhere.
  • If the target application runs elevated, run Auto Clicker as administrator too, Windows ignores synthetic input from a lower-privileged process.
