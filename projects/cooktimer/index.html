Cook Timer is a small, portable kitchen countdown timer for Windows.

It is written in pure C99 against the Win32 API, with no frameworks and no runtime dependencies beyond what ships with Windows. The interface is drawn entirely by hand, which keeps the same consistent dark theme as Auto Clicker, and full per-monitor DPI awareness keeps it crisp on scaled and multi-monitor setups.

Choose a preset or set the exact hours, minutes and seconds. The remaining time is repeated in the window title and on the taskbar button, which fills green while cooking, turns yellow on pause and red when the time is up. The alarm is a neutral three-tone beep, and both the settings and the window position are remembered between runs.

— Polina “Aura” N. & Julia Nechaevskaya

Usage

  • Pick a 3, 5 or 10 minute preset, or choose Custom and set hours, minutes and seconds by typing, with the arrow keys, the mouse wheel or the small spinners.
  • Start begins the countdown and becomes Pause; Reset returns to the configured time.
  • Automatic restart starts the next round 2.5 seconds after zero, so the display still shows the finished time for a moment.
  • Ring forever keeps the alarm sounding until it is stopped. With both options enabled the alarm ends when the next round begins.
  • The taskbar button shows the progress, the same way Explorer does while copying files.
  • Settings and the window position are saved in cooktimer.ini next to the executable, so the whole folder can be moved anywhere.
